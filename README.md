
# Software FJ

## Sistema Integral de Gestión de Clientes, Servicios y Reservas

Aplicación desarrollada en Python mediante programación orientada a objetos.

### Objetivo

Desarrollar un sistema que permita gestionar clientes, servicios y reservas para la empresa Software FJ, garantizando estabilidad, modularidad y manejo robusto de excepciones.

### Tecnologías

- Python
- Programación orientada a objetos
- Git
- GitHub
- Archivos de registro (logs)

### Funcionalidades principales

- Gestión de clientes.
- Administración de servicios.
- Gestión de reservas.
- Validaciones y excepciones personalizadas.
- Registro de eventos y errores.
